## 4. 发布步骤（三选一，按本地 Agent 的能力）

### 方案 A · 浏览器网页上传（推荐，最贴合"操控浏览器"）

适合：本地有浏览器、已登录 GitHub，但不一定装了 git。缺点：271 个文件网页上传较慢，且 GitHub 网页单次上传有数量上限，可能需要分批。

1. 打开 https://github.com/new
2. 登录（若未登录）
3. Repository name 填 `beifeng-reader`
4. Description 填 §3 那句
5. 选 **Public**
6. **不要**勾 "Add a README file" / ".gitignore" / "license"
7. 点 **Create repository**
8. 进入空仓库后，点 **uploading an existing file**（或 "Add file → Upload files"）
9. 把解压后的 `beifeng-reader/` 里**全部文件**拖进去（含隐藏的 `.gitignore`）
10. 等上传完成，点 **Commit changes**
11. 如果一次传不完，重复 8–10 分批追加
12. 验证：仓库首页能看到 README 渲染、screenshots 图片、LICENSE

### 方案 B · 本地 git 推送（最快最稳，推荐优先试）

适合：本地装了 git 且有 GitHub 凭据（gh 已登录或凭据管理器有）。

```bash
cd beifeng-reader
git init -q
git config user.name "Beifeng contributors"
git config user.email "bytelate@163.com"
git add -A
git commit -m "初始提交：北风单文件离线阅读器"

# 先去 https://github.com/new 建空仓库（按 §3，不要勾初始化选项），拿到地址后：
git branch -M main
git remote add origin https://github.com/<你的用户名>/beifeng-reader.git
git push -u origin main
```

如果 `git push` 弹登录：用浏览器登录 GitHub，或生成 Personal Access Token（勾 `repo`）当密码用。

### 方案 C · gh CLI（如果本地装了 gh）

```bash
gh auth login          # 浏览器登录，一次搞定
cd beifeng-reader
gh repo create beifeng-reader --public --source=. --remote=origin --push \
  --description "单文件离线小说阅读器 · An offline-first novel reader in a single HTML file"
```

这一步会自动建仓库 + 推送，最省事。
